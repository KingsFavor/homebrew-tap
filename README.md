# homebrew-tap

KingsFavor 도구용 Homebrew tap.

## Port Killer

macOS 메뉴바 개발 포트 관리 도구 → [KingsFavor/Mac-port-viewer](https://github.com/KingsFavor/Mac-port-viewer)

```bash
brew install --cask kingsfavor/tap/port-killer
```

> 공증 전 빌드는 `--no-quarantine` 를 붙이면 Gatekeeper 경고를 우회합니다.

Cask 는 릴리즈 CI가 자동으로 최신 버전으로 갱신합니다.
